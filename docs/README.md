# Docs Index

This repository keeps durable project knowledge under `docs/`.

## Repository Layout

- `.agents/`
  - repo-local agent assets and reusable prompts
  - not a durable knowledge base

- `docs/ai/`
  - shared AI knowledge for this repository
  - project overview and future module notes

- `docs/roadmap.md`
  - current project status and next work

- `docs/design.md`
  - integration design and entity/control boundaries

- `docs/api-notes.md`
  - official cloud API notes and reverse-engineering findings

## Suggested Read Paths

### For Humans

1. `README.md`
2. `docs/roadmap.md`
3. `docs/design.md`
4. `docs/api-notes.md`

### For Agents

1. `AGENTS.md`
2. `docs/ai/project-overview.md`
3. `docs/roadmap.md`
4. the smallest relevant design or API note
